# 투자 시뮬레이터 (주식 + 코인)

브라우저에서 바로 실행 가능한 실전형 시뮬레이터입니다.

## 기능
- 초기자산 + 월 적립금 기반 복리 시뮬레이션
- 주식/코인/현금 비중 및 기대수익률/변동성 입력
- 몬테카를로(랜덤 경로)로 목표금액 달성 확률 계산
- 결과: 중앙값, 하위10%, 상위10%, 목표달성확률, 샤프지수(연환산), 최대낙폭(MDD)
- `finals CSV 다운로드` 버튼으로 시뮬레이션 최종값 내보내기
- 보수/기본/공격 프리셋
- 모바일(480px 이하) 1열 레이아웃 최적화
- 초보자용 3단계 가이드 UI + 비중 합계/코인 리스크 배지 실시간 표시

## 실행 방법
### 방법 1) 파일 더블클릭
`index.html` 열기

### 방법 2) 로컬 서버 실행 (권장)
```bash
cd investment-simulator
python -m http.server 8080
```
브라우저에서 `http://localhost:8080` 접속

## 사용 방법 (핵심)
1. 초기자산/월 적립금/기간/목표금액 입력
2. 주식·코인·현금 비중(합계 100)과 기대수익률/변동성 설정
3. `시뮬레이션 실행` 클릭
4. 필요하면 `finals CSV 다운로드`로 최종값 목록 저장

## 활용 팁
- 코인 비중을 5~35% 범위에서 바꿔보며 MDD/목표확률/샤프지수를 함께 비교하세요.
- 목표확률이 70% 이상 나오도록 월 적립금/기간/비중을 조정하면 계획에 현실성이 생깁니다.
- 같은 조건에서도 매번 값이 조금씩 달라집니다(확률 시뮬레이션 특성).

## 주의
- 이 도구는 **투자 조언이 아닌 계획 시뮬레이션 도구**입니다.
- 실제 시장은 분포 왜곡, 급락 갭, 유동성 문제 등으로 더 불리할 수 있습니다.
