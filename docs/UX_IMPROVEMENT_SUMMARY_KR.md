# 초보자 UX 개선 요약

## 왜 이 프로젝트가 어렵게 보였나

1. 기능이 많고, 초보자용 기본 흐름과 고급 기능이 같은 층위에서 보였다.
2. 첫 실행 시 "무엇부터 해야 하는지"를 빠르게 이해할 수 있는 시작 문장이 약했다.
3. 노트 문법 입력은 강력하지만, 처음 보는 사용자에게는 메모 규칙처럼 느껴졌다.
4. Guided Editor가 있어도 전체 사용자 여정이 문서와 명령어에 충분히 드러나지 않았다.
5. 보고서에 중요한 정보가 많지만, 초보자가 맨 먼저 읽어야 할 요약이 약했다.

## 기본 기능 vs 고급 기능

기본 기능:
- 빠른 시작 템플릿
- Guided Editor
- 현재 노트 분석
- 결과 읽기

고급 기능:
- OCR JSON
- 로컬 OCR bridge
- JSON profile
- Daily briefing
- Strategy league
- CSV export
- Omniforge handoff

## 개선 우선순위

1. 첫 실행 흐름을 3~4단계로 고정
2. 명령어 이름을 초보자용 / 고급용으로 구분
3. 기본 템플릿을 최소 입력 중심으로 단순화
4. 결과 보고서 상단에 짧은 해석 요약 제공
5. 초보자 가이드와 고급 가이드를 문서로 분리

## 첫 실행 사용자 여정

이전:
- README 읽기
- 어떤 명령어를 먼저 써야 할지 고민
- 긴 템플릿과 고급 섹션을 함께 봄
- 결과가 나와도 어디부터 읽어야 할지 망설임

개선 후:
- `Start here` 명령 실행
- 최소 입력만 수정
- `Analyze current note` 실행
- `Read This First`부터 읽기

## 이번 정리의 핵심 방향

- 기능 삭제가 아니라 레이어 분리
- 초보자에게는 첫 성공 경험을 먼저 제공
- 고급 기능은 뒤로 배치하되 그대로 유지
- 숫자 옆에 의미를 함께 보여주기
